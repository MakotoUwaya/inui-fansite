# 楽曲再生時間チェック・修正ワークフロー (check-song-length)

歌枠アーカイブの楽曲データにおいて、タイムスタンプが歌唱終了時刻ではなく次の曲の直前まで設定されているなどの原因で、**歌唱終了後の長時間の雑談部分（数分単位）が含まれてしまっている楽曲**を調査・修正するためのスキルです。

公式音源尺（iTunes Search API）の単純加算だけでは、カラオケ音源のアウトロ短縮やアレンジ、ワンコーラス等により20秒以上のズレが発生するため、**yt-dlp によるピンポイント音声切り出しと Antigravity（Gemini）による実音声直接試聴（view_file）** を必須の核として、1秒の狂いもなく正確に歌唱終了時刻を特定します。

## 🎯 役割分担と設計思想

```
┌──────────────────────────────────────────────┐
│ スクリプト (scripts/check-song-length.ts)    │
│ ・DBから未チェック曲・現行区間の抽出         │
│ ・iTunes Search API で公式尺取得（目安区間） │
│ ・yt-dlp で終了推定付近（前後20〜40秒）を    │
│   ピンポイント音声切り出し（数秒でダウンロード）│
└──────────────────────┬───────────────────────┘
                       │ 音声クリップ生成 (tmp/audio-clips/range-*.mp3)
                       ▼
┌──────────────────────────────────────────────┐
│ Antigravity (Gemini エージェント)            │
│ ・view_file で音声ファイルを「直接試聴」     │
│ ・伴奏の最後の音が消える瞬間（終了秒数）特定 │
│ ・ライバーのトーク開始直前の秒数を1秒単位で特定│
│ ・DBへの正確な終了時刻（end）の反映          │
└──────────────────────────────────────────────┘
```

## 🖥️ ローカル微調整用 Web UI（目視・耳で確認する場合）

ブラウザ上で動画を再生・試聴しながら、開始時刻・終了時刻を数秒で微調整できるローカル開発限定画面も利用可能です。

```bash
# 開発サーバーを起動
pnpm.cmd dev

# ブラウザでアクセス（ローカル環境のみアクセス可能）
# http://localhost:3000/admin/adjust-length
```

- **機能**:
  - 未確認 / 確認済みの切り替え、インクリメンタル検索、曲長順ソート
  - 「歌い出し確認」「歌い終わり確認」「終了後雑談確認」の各試聴ボタン
  - キーボード `[` / `]` で開始/終了時刻にセット、`Ctrl + Enter` で保存して次の曲へ自動遷移

## 🛠️ コマンド一覧（CLI）

すべての操作は `scripts/check-song-length.ts` を通じて行います。

```bash
# 1. 進捗サマリーの表示（総曲数、5分以上曲数、未チェック曲数）
pnpm.cmd exec tsx scripts/check-song-length.ts --stats

# 2. 未チェック一覧の通常表示（特定動画の全曲）
pnpm.cmd exec tsx scripts/check-song-length.ts --list --video-id <VIDEO_ID> --all --threshold 0

# 3. 音声ピンポイント切り出し（任意区間）
# 例: 18分00秒から18分45秒までを切り出し
pnpm.cmd exec tsx scripts/check-song-length.ts --clip-range --video-id <VIDEO_ID> --start 18:00 --end 18:45

# 4. 終了時刻を更新（is_length_checked も自動で true になります）
pnpm.cmd exec tsx scripts/check-song-length.ts --update <ID> --end 18:41

# 5. 長さは正常として確認済みにマーク
pnpm.cmd exec tsx scripts/check-song-length.ts --mark-ok <ID>
```

## 📋 Antigravity 自律実行ワークフロー

### ステップ 1: 対象動画の楽曲一覧と目安時刻の算出
特定動画の全曲について、開始時刻（`start`）、現行終了（`end`）、次曲開始（`nextStart`）、公式音源尺を取得します。

- 終了推定の目安: `start + officialDuration`（ただしカラオケ音源やアレンジによって±20秒前後ズレる前提で扱う）

### ステップ 2: yt-dlp によるピンポイント音声切り出し
推定終了時刻の前後（約30〜40秒間）を `--clip-range` で切り出します。
（例: 推定が 18:30 の場合、`--start 18:10 --end 18:50` で切り出し）

### ステップ 3: view_file による実音声直接試聴 & 正確な終了時刻特定
Antigravity は `view_file` ツールで切り出された mp3 を直接開き、音声を聴き取ります：
1. **歌唱パートの終了** を確認
2. **伴奏（後奏・ギター/ピアノの余韻）の最後の音が消える瞬間** の秒数を特定
3. **ライバーの喋り声（「はい、〇〇でした〜」など）が始まる直前の秒数** を特定
4. 1秒単位で正確な `end` を決定

### ステップ 4: DBへの反映とクリーンアップ
特定した正確な終了時刻を DB（`singing_stream` テーブル）へ反映します。
- ユーザーが Web UI（`/admin/adjust-length`）で確認作業を行う前提の場合は、`end` のみを更新し、`is_length_checked` は `false` のまま保持することで、ユーザーは「歌い終わり確認ボタンを押して即OK」の超快適な状態で確認を進められます。
- 一時切り出した音声ファイル（`tmp/audio-clips/`）は削除してクリーンアップします。

### ステップ 5: 完了報告
各楽曲の「確定終了時刻」と「実音声試聴ログ（演奏終了秒・トーク開始秒）」を表形式で端的にユーザーへ報告します。
