# 曲登録スキル (add-songs)

歌枠のYouTube動画URLおよび有志コメントのタイムテーブルを受け取り、全自動でSupabaseデータベースに登録する手順です。
ユーザーへの余計な途中確認は挟まず、自律的に登録完了まで実行します。

## 登録ワークフロー（完全自律実行）

1. **タイムテーブルテキストの保存**:
   ユーザーから受け取った有志コメント（タイムテーブル）を一時ファイル（`temp-timetable.txt`）に保存する。

2. **登録スクリプトの一発実行**:
   以下のコマンドを実行する（スクリプト内でYouTubeタイトル取得、絵文字除去・パース、iTunes APIによる原曲長・終了時刻の自動計算、Supabaseへの一括DB登録までが全自動で行われます）。

   ```bash
   npm run add-songs -- "<YouTube動画URLまたはVideoId>" temp-timetable.txt
   ```

3. **一時ファイルの削除**:
   `Remove-Item temp-timetable.txt` で一時ファイルを削除する。

4. **結果の簡潔な報告**:
   登録された曲数、動画タイトル、各曲の演奏区間の一覧を簡潔に報告する。
