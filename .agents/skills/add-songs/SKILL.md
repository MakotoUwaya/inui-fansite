# 楽曲登録スキル (add-songs)

YouTube動画URL（歌枠または単曲動画）を受け取り、全自動でSupabaseデータベースに登録し、関連する設定（ライバーアイコン・アバター等）を整合させて検証まで完了するワークフローです。
ユーザーへの余計な途中確認は挟まず、自律的に登録完了まで実行します。

---

## 登録ワークフロー（完全自律実行）

### パターンA: 通常の歌枠（コメントタイムテーブルあり）
1. **タイムテーブルの準備**:
   ユーザーから受け取った有志コメント（タイムテーブル）を一時ファイル（`temp-timetable.txt`）に保存する。
2. **登録スクリプトの実行**:
   ```bash
   pnpm exec tsx --env-file=.env.local scripts/add-songs.ts "<YouTube動画URL>" temp-timetable.txt
   ```
   - コラボ歌枠の場合、タイムテーブル内の絵文字（🍹, 💡, 🐌, 🍬, 🥨🍚, 🧸🌙, 🌶, 🍝 等）や「ソロ」「デュエット」「全員」などの表記から、曲ごとの正確な歌唱者（`singers`）が自動判定・反映されます。
3. **一時ファイルの削除**:
   `Remove-Item temp-timetable.txt` で一時ファイルを削除する。

### パターンB: 単曲動画（MV / 歌ってみた / 9分未満の動画）
タイムテーブルは不要です。動画URLのみを渡してスクリプトを実行します。
（再生時間が9分未満の場合は自動的に単曲と判定され、タイトルから曲名・アーティスト名を推測して `00:00 〜 動画末尾` で登録されます）

```bash
pnpm exec tsx --env-file=.env.local scripts/add-songs.ts "<YouTube動画URL>"
```
※曲名やアーティスト名を明示したい場合は `--title "曲名" --artist "アーティスト"` オプションを付与可能。

---

## 🏷️ 登録後の自動ポスト処理（タグ付け & 曲長チェック・雑談カット）

楽曲登録時、`scripts/add-songs.ts` 内部で以下の処理が**完全自動**で実行されます：

1. **Jev による自動タグ付け (`add-tags` スキル連携)**:
   - TypeSafe AI (Jev) により、楽曲のムード（`ballad`, `emotional`, `cool`, `bright`, `jazz_rnb`）、ジャンル（`vocaloid`, `anime`, `jpop`, `nostalgic`, `vtuber`）、夜曲適性（`is_night_pick`）が即座に判定・保存されます。
   - ※万一スキップや失敗があった場合は、事後に `pnpm exec tsx scripts/tag-all-songs.ts` を実行して未タグ曲を補完します。

2. **Antigravity による歌唱区間診断・雑談カット (`check-song-length` スキル連携)**:
   - 登録完了後、`pnpm exec tsx scripts/check-song-length.ts --inspect --video-id <VIDEO_ID> --threshold 0` を実行し、Antigravity（Gemini）が公式音源尺との差分や次曲タイムラインを推論。
   - 歌唱後の長時間の雑談が含まれている曲を自動特定し、適正な終了時刻（`end`）へ補正（または適正承認）します。
   - ※目視・耳で細かく確認・微調整したい場合は、ローカル微調整UI（`http://localhost:3000/admin/adjust-length`）でブラウザから即座に調整可能です。

## 新規ライバー登場時のアバター・アイコン設定（必須チェック）

登録された楽曲の歌唱者（`singers`）に、まだサイト未設定の新規ライバーが含まれている場合、**自動的に設定を追加**します。

1. **`utils/singerConfig.ts` の確認**:
   - `SINGER_ICONS`: ライバーの公式ファンマーク（推しマーク絵文字）が登録されているか確認し、未登録なら追加する。
   - `SINGER_AVATARS`: 公式YouTubeアバター画像URLが登録されているか確認し、未登録なら追加する。
2. **アバター画像URLの取得と取り違え防止ルール**:
   - **公式チャンネルの特定**: 切り抜きチャンネルや同名別アカウントとの取り違えを防ぐため、必ず公式のチャンネルハンドル（例: `@KadouMikaru`）またはチャンネルID（`UC...`）を確認して取得する。
   - **高画質URL形式**: `https://yt3.googleusercontent.com/...=s900-c-k-c0x00ffffff-no-rj` 形式のURLを使用する。

## 完了後の検証とコミットルール

楽曲登録および設定ファイルの更新が完了したら、必ず以下の工程を自律的に進めます：

1. **ユニットテストの実行**:
   ```bash
   pnpm test
   ```
   - 全テストが PASS することを確認する。
2. **プロダクションビルドの実行**:
   ```bash
   pnpm build
   ```
   - 静的ページ生成（SSG）を含めビルドエラーがないことを確認する。
3. **一括コミットの作成**:
   - 作業ステップごとに細かくコミットせず、一通りの更新・検証が完了した段階で1つのコミットにまとめる。
4. **git push の確認（必須）**:
   - プロジェクト運用ルールに従い、`git push` 前に変更内容の要約を提示してユーザーに承認を求める。
