# 曲登録スキル (add-songs)

歌枠のYouTube動画URLおよび有志コメントのタイムテーブルから楽曲情報を抽出し、Supabaseデータベースに登録する手順です。

## 登録ワークフロー

### 1. 入力情報の整理
ユーザーから以下の情報を受け取ります。
- **YouTube動画URL**（例: `https://www.youtube.com/watch?v=sz3SGilaOAA`）
- **有志コメント（タイムテーブル）**

### 2. コメントのパースと正規化
コメントテキストから各楽曲の情報を抽出します。
- **開始時刻 (start)**: `MM:SS` または `H:MM:SS` を秒数に変換（例: `6:57` → `417` 秒）。
- **終了時刻 (end) の算出**:
  - 歌枠では曲間に雑談が入るため、「次の曲の開始時刻」をそのまま使うと雑談まで含まれてしまいます。
  - **iTunes Search API から原曲の再生時間を自動取得** し、`開始時刻 + 原曲の長さ + アウトロバッファ（約8秒）` を終了時刻とします。
  - 次の曲の開始時刻までの間隔が原曲より短い場合は、次の曲の開始時刻を上限とします。
- **曲名 (title)** / **アーティスト名 (artist)**:
  - 絵文字（🍹, ☯️ など）や装飾・注記を除去。
  - スラッシュ `/` 等で区切られている場合は `曲名 / アーティスト名` に分割。
  - 歌唱でないノイズ行（「声入り」「OP」「ED」「分用 敬称略」など）は除外。

### 3. ユーザーへの事前確認
抽出・計算した楽曲リストを表形式でユーザーに提示し、曲名やアーティスト名、演奏区間に問題がないか確認を取ります。

| No | 曲名 | アーティスト名 | 開始時刻 | 推定終了時刻 | 原曲の長さ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 未来予想図II | DREAMS COME TRUE | 06:57 (417s) | 12:11 (731s) | 5:06 |
| ... | ... | ... | ... | ... | ... |

### 4. 登録スクリプトの実行
確認が取れたら、JSONデータを一時ファイル（例: `temp-songs.json`）に保存し、登録スクリプトを実行します。

```json
{
  "video": {
    "video_id": "sz3SGilaOAA",
    "title": "【コラボ歌枠】ノリで集まったふたりで平成ヒットソングを辿っていく回【戌亥とこ/長尾景/にじさんじ】",
    "url": "https://www.youtube.com/watch?v=sz3SGilaOAA",
    "published_at": "2022-08-20T12:00:00Z"
  },
  "songs": [
    {
      "title": "未来予想図II",
      "artist": "DREAMS COME TRUE",
      "start": 417
    }
  ]
}
```
※ `end` を省略した場合、スクリプト側でも自動的に iTunes API で原曲長を取得・補正します。

コマンド実行:
```bash
npm run add-songs temp-songs.json
```

実行後、一時ファイル `temp-songs.json` を削除します。

### 5. 登録完了の報告
登録された動画タイトル、総曲数、および登録ステータスをユーザーに報告します。
