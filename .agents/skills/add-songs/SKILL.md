# 曲登録スキル (add-songs)

歌枠のYouTube動画URLおよび有志コメントのタイムテーブルから楽曲情報を抽出し、Supabaseデータベースに登録する手順です。

## 登録ワークフロー

### 1. 入力情報の整理
ユーザーから以下の情報を受け取ります。
- **YouTube動画URL**（例: `https://www.youtube.com/watch?v=sz3SGilaOAA`）
- **有志コメント（タイムテーブル）**

### 2. コメントのパースと正規化
コメントテキストから各楽曲の情報を抽出します。
- **開始時刻 (start)**: `MM:SS` または `H:MM:SS` を秒数に変換（例: `6:57` → `417` 秒）。
- **終了時刻 (end)**:
  - 基本ルール: **「次の曲（または次の区切り）の開始時刻」** を終了時刻とする。
  - 最後の曲: 動画の長さが分かればその秒数、不明な場合は「開始時刻 + 240秒（4分）」を暫定セット。
- **曲名 (title)** / **アーティスト名 (artist)**:
  - 絵文字（🍹, ☯️ など）や装飾・注記を除去。
  - スラッシュ `/` 等で区切られている場合は `曲名 / アーティスト名` に分割。
  - 歌唱でないノイズ行（「声入り」「OP」「ED」「分用 敬称略」など）は除外。

### 3. ユーザーへの事前確認
抽出した楽曲リストを表形式でユーザーに提示し、曲名やアーティスト名、区間に誤りがないか確認を取ります。

| No | 曲名 | アーティスト名 | 開始 (秒) | 終了 (秒) |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 未来予想図II | DREAMS COME TRUE | 06:57 (417) | 19:08 (1148) |
| ... | ... | ... | ... | ... |

### 4. 登録スクリプトの実行
確認が取れたら、JSONデータを一時ファイル（例: `temp-songs.json`）に保存し、登録スクリプトを実行します。

```json
{
  "video": {
    "video_id": "sz3SGilaOAA",
    "title": "動画タイトル（歌枠名）",
    "url": "https://www.youtube.com/watch?v=sz3SGilaOAA",
    "published_at": "2022-08-20T12:00:00Z",
    "length": 7200
  },
  "songs": [
    {
      "title": "未来予想図II",
      "artist": "DREAMS COME TRUE",
      "start": 417,
      "end": 1148
    }
  ]
}
```

コマンド実行:
```bash
npm run add-songs temp-songs.json
```

実行後、一時ファイル `temp-songs.json` を削除します。

### 5. 登録完了の報告
登録された動画ID、総曲数、および登録ステータスをユーザーに報告します。
