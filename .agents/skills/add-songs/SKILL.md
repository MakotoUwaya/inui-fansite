# 曲登録スキル (add-songs)

YouTube動画URL（歌枠または単曲動画）を受け取り、全自動でSupabaseデータベースに登録する手順です。
ユーザーへの余計な途中確認は挟まず、自律的に登録完了まで実行します。

## 登録ワークフロー（完全自律実行）

### パターンA: 通常の歌枠（コメントタイムテーブルあり）
1. ユーザーから受け取った有志コメント（タイムテーブル）を一時ファイル（`temp-timetable.txt`）に保存する。
2. スクリプトを実行する：
   ```bash
   npm run add-songs -- "<YouTube動画URL>" temp-timetable.txt
   ```
3. `Remove-Item temp-timetable.txt` で一時ファイルを削除する。
4. 登録結果（動画タイトル、曲数、各曲の演奏区間）を簡潔に報告する。

### パターンB: 単曲動画（MV / 歌ってみた / 9分未満の動画）
タイムテーブルは不要です。動画URLのみを渡してスクリプトを実行します。
（再生時間が9分未満の場合は自動的に単曲と判定され、タイトルから曲名・アーティスト名を推測して `00:00 〜 動画末尾` で登録されます）

```bash
npm run add-songs -- "<YouTube動画URL>"
```
※曲名やアーティスト名を明示したい場合は `--title "曲名" --artist "アーティスト"` オプションを付与可能。
